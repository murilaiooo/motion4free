# Contribuindo com Motion4Free

O projeto está em concepção. Primeiro leia [docs/INDEX.md](docs/INDEX.md), [requisitos](docs/requirements.md) e a [spec Superpowers](docs/superpowers/specs/2026-10-18-motion4free-design.md).

- Preferir PT-BR para documentação; nomes técnicos e schemas podem ser em inglês.
- Manter os componentes de um projeto no mesmo repositório; responsabilidades e diretórios claros.
- Trabalho novo: spec aprovada, plano Superpowers, implementação pequena, testes, revisão independente.
- Issues devem ter objetivo, risco, evidência e definição de pronto.
- PRs precisam explicar comportamento alterado, testes e screenshots/amostra quando houver UI/motion.
- Não adicionar API obrigatoriamente paga, backend GPU ou upload sem autorização.
- Nunca commitar mídia original, tokens, cookies, arquivos pessoais, modelos pesados sem licença.
- Assets precisam de proveniência, condição de uso, restrições, preview e licença individual.
- Benchmark editorial humano é necessário para afirmar qualidade, além dos testes técnicos.

Ver [Segurança](SECURITY.md).
