# #26 / #28 — protótipo isolado de três composições, QA local executado

Entrada de pesquisa em `/research/frame-compositor/index.html` ao servir o repositório via Vite local. Não é importada pela interface de produção e não adiciona biblioteca ao runtime publicado. A implementação foi **testada no Brave** com 3 exportações sintéticas e inspeção de frames; veja `docs/reviews/2026-10-24-issue26-composition-proof.md`. Este protótipo NÃO equivale ao recurso integrado no app.

Common composition: identical bounded declarative graph, text and geometry, sampled from absolute time. Canvas2D adapter and Three.js 0.180.0 orthographic adapter share stateAt; no engine clock, random values, executable payload, external media, shader or user-provided URL. Schema caps 80 nodes, 540×960 and 120 seconds. Both adapters dispose resources. PNG capture invokes the same renderAt path as display. Three module is an explicit fixed-version CDN download; MIT notice accompanies it. No copied upstream example or asset. System sans-serif is platform-dependent, so cross-device typography equality is not claimed. Box3d is supported by Three; Canvas shows its flat rectangle projection, which is NOT a 3D parity claim. Common comparison graph uses only shared 2D primitives.

QA in Brave: serve the source, open the POC, inspect common graph at fixed/fractional times in forward and shuffled order and save same-time frames. Compare adapters' composition/placement and document rasterization/color differences, not an assumed cross-engine pixel identity. Compare a saved frame to that engine's displayed output. Try unknown node kinds/properties, external URLs, invalid colors/IDs/NaN/negative/reversed times, oversized graphs. Load/dispose repeatedly and collect JS/GPU allocation and CPU/GPU submission evidence using browser tooling. WebGL unavailable/CDN failure must leave Canvas usable with M4F-807. Capture exact browser/hardware/version/resolution, latency and memory samples; none exist yet.

Audio/muxed MP4 and source video decoding are intentionally not reimplemented in this research increment. They require a separate integration against the existing Mediabunny pipeline before any engine adoption. Motion Canvas/Pixi/Theatre/GSAP/dotLottie/OpenReel are documented candidates, not implemented adapters in this POC. Source-of-truth ADR-0005 remains unchanged; no winner can be selected from unexecuted code. #2 corresponding-source/license blockers remain independent. #26 adds structurally different compositions on this common foundation.

Primary references read: https://threejs.org/docs/ ; https://github.com/mrdoob/three.js/blob/r180/LICENSE ; npm metadata three@0.180.0. Module origin https://cdn.jsdelivr.net/npm/three@0.180.0/build/three.module.js (imports its same-version three.core.js). Research network dependency only, never receives user content.
