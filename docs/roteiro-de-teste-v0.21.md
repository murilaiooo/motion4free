# Roteiro de teste da v0.21 — primeira tela nova

Confira no rodapé **Motion4Free v0.21.0** (se precisar, aperte Ctrl+Shift+R).

1. Abra o site. No alto aparecem o título "Grave. Solte aqui. Poste editado.", o botão **Escolher vídeos** e, à direita, uma janela mostrando como o editor se parece, com o vídeo de exemplo animado.
2. Role a página: Como funciona, Tudo o que o editor faz, Modelos prontos, a faixa escura de privacidade, Perguntas e, por fim, o botão final.
3. Clique no botão final **Escolher vídeos**: a página volta ao topo.
4. Se você tiver projetos salvos, eles aparecem logo abaixo da abertura.
5. Abra pelo celular: tudo deve caber na tela, sem nada cortado.
6. Escolha um vídeo e confira se a edição começa normalmente.
